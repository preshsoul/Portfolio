# Precious Ajayi Portfolio

Personal portfolio for Precious Ajayi — research, strategy, writing and editorial operations for work that has to hold up.

The site is structured around proof-aware case studies, published research, writing, decision tools and a direct inquiry path.

## What is inside

- Selected case studies with context, role, method, deliverables, outcomes and proof boundaries.
- A visible artifact layer for models, proposal workflows, editorial systems and research excerpts.
- Published research and writing links, including Substack and Selar work.
- Products/tools page for frameworks and field manuals.
- Accessible contact flow that opens a prefilled email draft.

## Scripts

```bash
npm start
npm test -- --watchAll=false --runInBand
npm run build
```

## Deployment

Changes are pushed to the `main` branch of the `portfolio` repository for the deployed site to pick up.
